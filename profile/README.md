# AI Native Solutions

Software-Herz der Firma. Hier liegt der Code für interne Produkte, Kundenprojekte und die Vorlagen, auf denen neue Arbeit aufsetzt.

Wir bauen **AI-native Software** — Anwendungen, in denen Coding-Agents, klare Workflows und wiederverwendbare Setups zum Standard gehören, nicht zum Extra.

## Was wir bauen

| Richtung                       | Status    | Kurz                                                                          |
| ------------------------------ | --------- | ----------------------------------------------------------------------------- |
| Organisation / Task Management | geplant   | Software, mit der die Firma Arbeit plant, verteilt und nachverfolgt           |
| Ideen-Dashboard                | geplant   | Tracking von Produkt- und Projektideen, vom Inbox-Status bis zur Entscheidung |
| Hosting / Deploy-Service       | geplant   | Workflow der Art _„publish App X auf Domain X“_ (intern: Hermes)              |
| Standard-Setup                 | in Arbeit | Gemeinsame Templates und Feature-Branches, auf denen andere aufbauen          |

Nicht jede Idee startet sofort. Repos ohne Code bleiben als Platzhalter sichtbar, bis die Beschreibung und der erste Commit nachziehen.
